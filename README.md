# AdPilot

**Платформа для управления рекламными кампаниями с интерфейсом ИИ-ассистента.**

AdPilot — учебный Fullstack-проект, направленный на разработку платформы для управления рекламными каналами, планирования рекламных кампаний, контроля бюджета и отслеживания активности.

Проект разрабатывается с использованием React и TypeScript. В дальнейшем планируется создание собственного Backend, подключение PostgreSQL и интеграция локальной языковой модели.

---

## Возможности

### 📊 Dashboard
- Панель с основной статистикой.
- График активности.
- Информация о рекламных кампаниях.
- Последние события.

### 📢 Рекламные каналы
- Просмотр списка рекламных площадок.
- Поиск каналов.
- Фильтрация и сортировка.
- Просмотр подробной информации о канале.
- Отображение характеристик: количество подписчиков, ER, CPM и стоимость размещения.

### 📋 Рекламные кампании
- Создание рекламных кампаний.
- Просмотр подробной информации.
- Редактирование существующих кампаний.
- Выбор рекламных каналов.
- Контроль бюджета и стоимости размещения.
- Проверка корректности введённых данных.
- Сохранение стоимости размещения на момент добавления канала в кампанию.

### 📈 Журнал активности
- Отслеживание создания кампаний.
- Фиксация изменений кампаний.
- Отображение изменений бюджета и выбранных каналов.
- Фильтрация и поиск событий.

### 🤖 AI Assistant
- Интерфейс общения с ИИ-ассистентом.
- Создание и переключение между диалогами.
- Отображение истории сообщений.
- Быстрые подсказки для взаимодействия.
- Демонстрационная логика ответов.

> AI Assistant пока работает в демонстрационном режиме. Подключение реальной языковой модели запланировано на следующих этапах разработки.

## Запуск проекта

### Требования
- Node.js
- npm
- Git

### Установка

Клонирование репозитория:

```bash
git clone https://github.com/zaragoza2223/AdPilot.git
```

Переход в папку Frontend:

```bash
cd AdPilot/frontend
```

Установка зависимостей:

```bash
npm install
```

Запуск локального сервера:

```bash
npm run dev
```

После запуска открой адрес:

```text
http://localhost:5173/
```

### Production build

Сборка проекта:

```bash
npm run build
```

## Текущее состояние проекта

На данный момент реализована Frontend-часть приложения.

- Основные страницы и пользовательские интерфейсы созданы.
- Для демонстрации используются mock-данные.
- Данные кампаний, активности и диалогов сохраняются локально там, где это предусмотрено реализацией.
- Backend и PostgreSQL пока не подключены.
- AI Assistant работает в Demo Mode.
